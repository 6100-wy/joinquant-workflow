# 月度分析模板（每月最后一个交易日收盘后执行）

## 产出

- 文档：`<VAULT>\07-股票投资\复盘\YYYY-MM_月度分析.md`
- 同步：更新 `股票投资首页.md` 当前状态段、`<LOG_ROOT>\复盘记录_YYYY-MM-DD.md` 工作日志

## 内容结构

### 1. 本月概览

- 月度累计收益 / 基准对照 / 最大回撤 / 波动率（三策略分别列出）
- 月末持仓与本月调仓次数、手续费合计
- 每日累计曲线（可用 jq_daily_analyze 脚本 + 导出 CSV 计算）

### 2. 事件复盘

- 回撤预警 / 止损 / 止盈事件及结果
- 集中持仓事件（如房地产ETF银华案例）
- 14:55 强制买入标的后表现
- RegimeP0 与走弱期判定分歧是否延续

### 3. 上实盘门槛逐项核对（模拟期观察清单第 6 节）

- [ ] 模拟期 ≥ 20 个交易日
- [ ] 实测滑点始终 ≤ 千一（记录在案）
- [ ] 最大回撤在心理线内（默认 20%）
- [ ] 聚宽实盘接口已开通并确认可用
- [ ] 单ETF 与五福52 类策略日收益相关性已分析（组合分散）
- [ ] 30 万底仓配置已定（低波/固收），未挪用

### 4. 策略存续决策（建议 + 用户拍板）

- 每个策略：继续模拟 / 转实盘 / 砍掉，附依据（收益、回撤、异常次数、门槛满足度）

### 5. 待议参数清单

- 本月积累的“想改参数”条目（只记录，不执行），逐条给理由与潜在影响

### 6. 下一月计划

- 重点观察项、待办实验、下月目标
